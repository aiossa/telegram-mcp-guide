# Подключаем Telegram к Claude Code

Пошаговая инструкция: как дать Claude Code доступ к вашему Telegram, чтобы он читал переписки, искал по ним, делал выжимки и готовил ответы. Занимает 15–20 минут. Писать код не нужно, но пару раз придётся открыть Терминал.

Сам пользуюсь этим каждый день. Самое полезное — утром попросить «что важного было в рабочих чатах за ночь» и не листать двадцать тредов.

> Инструкция для macOS. На Windows шаги те же, отличается только хранение ключей — об этом в конце.

---

## Что получится в итоге

После настройки в Claude Code можно писать обычным языком:

- «Сделай дайджест непрочитанных сообщений»
- «Найди переписку, где обсуждали смету по проекту X»
- «Перескажи последние 50 сообщений в чате команды»
- «Подготовь черновик ответа Ивану»

## Как это устроено

```
Telegram  ⇄  telegram-mcp (работает у вас на Маке)  ⇄  Claude Code
```

- **telegram-mcp** — открытый сервер ([github.com/chigwell/telegram-mcp](https://github.com/chigwell/telegram-mcp)). Он запускается у вас на компьютере и ходит в Telegram от вашего имени.
- **MCP** — способ, которым Claude Code подключает внешние инструменты. Что-то вроде плагинов.
- **Ключи доступа** хранятся только у вас, в Связке ключей macOS, и никуда не уходят.
- **Текст сообщений** уходит в Claude только тогда, когда вы сами просите с ним что-то сделать. По сути то же самое, что скопировать переписку в чат руками.

---

## Что понадобится

- [Claude Code](https://claude.ai/code) — приложение или CLI
- Python 3.10 или новее. Проверить: открыть Терминал (`Cmd + Пробел` → «Терминал» → Enter) и выполнить:
  ```bash
  python3 --version
  ```
  **Скорее всего, вы увидите `Python 3.9.x`** — это версия, которую macOS ставит «из коробки», и для telegram-mcp она не подходит. Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/) (большая жёлтая кнопка), запустите `.pkg` и пройдите его до конца. Затем **закройте и заново откройте Терминал** и проверьте ещё раз — должно быть 3.10 или выше.

  > Если `python3 --version` после установки всё ещё показывает 3.9 — выполните `python3.13 --version` (подставьте свою версию). Если она отвечает, используйте в шаге 2 `python3.13` вместо `python3`.
- Telegram на телефоне
- Облачный пароль Telegram, если у вас включена двухэтапная аутентификация. Если забыли — восстановите заранее, без него дальше не пройти.

## Быстрый путь: пусть Claude ведёт сам

Можно не делать шаги ниже руками, а попросить Claude Code провести по ним. Скопируйте в чат:

```text
Подключи мой Telegram к Claude Code через MCP-сервер https://github.com/chigwell/telegram-mcp.
Действуй по инструкции https://github.com/aiossa/telegram-mcp-guide и веди меня по шагам.
Ключи храни в Связке ключей macOS, не в .env.
Перед каждой установкой объясняй, что ставишь и зачем.
```

Claude сам склонирует репозиторий, поставит окружение и зарегистрирует сервер. Два места он сделать за вас не сможет — их придётся пройти руками:

1. **Шаг 1** — получить ключи на my.telegram.org (там вход по коду из Telegram).
2. **Шаг 3** — отсканировать QR-код телефоном. Скрипт для этого Claude попросит запустить в отдельном окне Терминала.

Если хочется понимать, что происходит, — ниже то же самое руками.

---

## Шаг 1. Ключи на my.telegram.org · 5 минут

Telegram выдаёт каждому «приложению» пару ключей: **API ID** и **API Hash**. Наше приложение — это ваш личный сервер telegram-mcp.

1. Откройте [my.telegram.org](https://my.telegram.org).
2. Введите номер телефона в международном формате: `+79991234567`.
3. Код придёт **в сам Telegram** (не СМС). Введите его.

<!-- 📸 images/01-my-telegram-login.png — страница входа my.telegram.org с полем телефона -->

4. Откройте **API development tools**.

<!-- 📸 images/02-api-development-tools.png — меню my.telegram.org, выделен пункт API development tools -->

5. Если приложения ещё нет, заполните форму:
   - **App title** — любое, например `Claude Integration`
   - **Short name** — латиницей, 5–32 символа, например `ivan_claude`. Если занято — добавьте цифры.
   - **Platform** — `Desktop`
   - Остальное можно не трогать.

<!-- 📸 images/03-create-app-form.png — заполненная форма создания приложения -->

6. Нажмите **Create application**. На странице появятся **App api_id** (число) и **App api_hash** (32 символа). Оставьте вкладку открытой — они понадобятся на шаге 3.

<!-- 📸 images/04-api-credentials.png — страница с api_id и api_hash (значения ЗАМАЗАНЫ) -->

> Бывает, что форма отвечает просто «ERROR» без объяснений. Обычно помогает другой браузер, отключённый VPN или повтор через несколько минут.

## Шаг 2. Ставим сервер · 3 минуты

В Терминале:

```bash
git clone https://github.com/chigwell/telegram-mcp.git ~/telegram-mcp
```

```bash
cd ~/telegram-mcp && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt qrcode
```

Первая команда скачивает сервер в папку `~/telegram-mcp`. Вторая создаёт для него отдельное окружение Python и ставит туда зависимости — так ничего не смешивается с остальной системой.

> Если macOS предложит установить «инструменты командной строки» для `git` — соглашайтесь, это 5–10 минут.

<!-- 📸 images/05-install-done.png — Терминал после успешной установки зависимостей -->

## Шаг 3. Входим в Telegram по QR-коду · 3 минуты

Серверу нужен **session string** — длинный токен, который позволяет работать от вашего имени без повторного ввода кода. Получим его входом по QR-коду, как в Telegram Desktop.

Скачайте скрипт из этого репозитория и запустите:

```bash
curl -fsSL https://raw.githubusercontent.com/aiossa/telegram-mcp-guide/main/scripts/session_qr.py -o ~/telegram-mcp/session_qr.py
```

```bash
cd ~/telegram-mcp && .venv/bin/python session_qr.py
```

1. Скрипт спросит **API ID** и **API Hash** — вставьте их со страницы из шага 1.
2. В Терминале появится QR-код. На телефоне: **Telegram → Настройки → Устройства → Подключить устройство** — и наведите камеру.
3. Если включена двухэтапная аутентификация — введите облачный пароль (символы при вводе не отображаются, это нормально).
4. macOS может спросить разрешение на доступ к Связке ключей — нажмите **Разрешить**.

<!-- 📸 images/06-qr-in-terminal.png — QR-код в Терминале -->
<!-- 📸 images/07-link-device-phone.png — экран «Подключить устройство» на телефоне -->

В конце будет «Готово. Вошли как …». Скрипт сам сложил все три ключа в Связку ключей macOS — **session string не показывается на экране**, его не нужно никуда копировать.

<!-- 📸 images/08-session-saved.png — сообщение «Готово. Вошли как …» -->

> **Почему QR, а не код из СМС.** У части аккаунтов Telegram молча не присылает код подтверждения для новых сессий. С QR такой проблемы нет.

Проверить, что ключи на месте:

```bash
security find-generic-password -a "api_id" -s "telegram-mcp" -w
```

Должен показаться ваш API ID.

## Шаг 4. Скрипт запуска · 1 минута

Claude Code будет запускать сервер через маленький скрипт: он достаёт ключи из Связки ключей и стартует telegram-mcp.

```bash
mkdir -p ~/.local/bin && curl -fsSL https://raw.githubusercontent.com/aiossa/telegram-mcp-guide/main/scripts/telegram-mcp-launcher -o ~/.local/bin/telegram-mcp-launcher && chmod +x ~/.local/bin/telegram-mcp-launcher
```

Что внутри — можно посмотреть в [scripts/telegram-mcp-launcher](scripts/telegram-mcp-launcher). Там 15 строк, ничего хитрого.

---

## Шаг 5. Регистрируем сервер в Claude Code · 1 минута

В **обычном** Терминале (не внутри чата Claude Code):

```bash
claude mcp add telegram-mcp -s user -- ~/.local/bin/telegram-mcp-launcher
```

Проверка:

```bash
claude mcp list
```

В списке должна быть строка `telegram-mcp` со статусом `Connected`.

<!-- 📸 images/09-mcp-list.png — вывод claude mcp list с telegram-mcp -->

Флаг `-s user` значит «доступно во всех проектах», а не только в текущей папке.

## Шаг 6. Проверяем

Перезапустите Claude Code (закрыть и открыть заново) и напишите в чат:

```text
Покажи мои последние чаты в Telegram
```

Claude один раз спросит разрешение на использование инструмента — разрешите. Если появился список чатов — всё работает.

## Безопасность — прочитайте, это важно

**Session string опаснее пароля.** Он обходит двухэтапную аутентификацию. С ним можно незаметно читать все чаты, писать от вашего имени, скачивать файлы и видеть контакты.

Поэтому:

1. **Никому не показывайте session string** и не коммитьте его в git. На записи экрана замазывайте API Hash.
2. **Отправку держите под контролем.** Пусть Claude готовит черновики, а отправляете вы. Или хотя бы требуйте показать текст перед отправкой.
3. **Включите двухэтапную аутентификацию** в Telegram, если ещё не.
4. **Иногда заглядывайте в активные сессии:** Настройки → Устройства. Там будет видна сессия telegram-mcp.
5. **Раз в 3 месяца перевыпускайте session string** — просто запустите шаг 3 ещё раз.
6. **Есть важные рабочие чаты — сначала попробуйте на втором аккаунте.**

Учтите: у telegram-mcp нет режима «только чтение» и нет фильтра по чатам. Он видит всё, что видите вы.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| Код подтверждения не приходит | Используйте вход по QR (шаг 3). Не запрашивайте код много раз подряд — Telegram ограничит попытки. |
| `externally-managed-environment` при установке | Вы ставите пакеты не в окружение. Повторите шаг 2 целиком — команда с `.venv`. |
| `telegram-mcp` нет в `claude mcp list` | `claude mcp remove telegram-mcp -s user`, затем шаг 5 заново и перезапуск Claude Code. |
| `✘ Failed to connect` | Запустите `~/.local/bin/telegram-mcp-launcher` в Терминале — ошибка будет видна. Чаще всего нет ключей в Связке ключей → повторите шаг 3. |
| `Session expired` / `AuthKeyUnregistered` | Сессию завершили в Telegram или она протухла. Повторите шаг 3. |
| `Could not find the input entity` | Неверный ID чата. У супергрупп ID начинается с `-100`, у каналов можно указать username без `@`. |

## Как отключить всё обратно

1. Telegram → Настройки → Устройства → завершите сессию telegram-mcp.
2. Удалите сервер из Claude Code и ключи из Связки ключей:
   ```bash
   claude mcp remove telegram-mcp -s user
   ```
   ```bash
   for a in api_id api_hash session_string; do security delete-generic-password -a "$a" -s "telegram-mcp"; done
   ```
3. Удалите файлы:
   ```bash
   rm -rf ~/telegram-mcp ~/.local/bin/telegram-mcp-launcher
   ```

## Windows

Шаги 1, 2, 3 и 5 те же (вместо `.venv/bin/python` — `.venv\Scripts\python`). Связки ключей на Windows нет, поэтому ключи кладут в файл `.env` в папке `telegram-mcp` — формат есть в README самого [telegram-mcp](https://github.com/chigwell/telegram-mcp). Закройте к этому файлу доступ другим пользователям и никогда не коммитьте его.
